# 2048 + Секретный калькулятор

Минималистичное веб‑приложение в современном стиле:

- полноценная игра **2048** на поле 4×4;
- счёт и лучший результат;
- управление с клавиатуры, кнопками на экране и свайпами на мобильных;
- скрытый калькулятор в том же визуальном стиле.

## Секретная активация калькулятора

В игровом режиме нажмите **5 раз подряд** на **вторую ячейку во втором ряду**.
После этого появится калькулятор.

## Калькулятор

Поддерживает базовые операции:

- `+`
- `-`
- `×`
- `÷`
- `C` (очистка)
- `=` (вычисление)

Кнопка **«Вернуться к игре»** закрывает калькулятор и возвращает вас к текущему состоянию игры.

## Локальный запуск

Это статический сайт, сборка не требуется.

1. Клонируйте репозиторий.
2. Откройте `index.html` в браузере.

## GitHub Pages

1. Запушьте репозиторий в GitHub.
2. Откройте `Settings → Pages`.
3. В `Build and deployment` выберите:
   - `Source: Deploy from a branch`
   - `Branch: main` и папку `/ (root)`
4. Сохраните настройки и дождитесь публикации.
